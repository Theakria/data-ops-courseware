课程结构

页面课堂用途
第一节：怎么围绕目标，建立数据化的思维框架用宠物险业绩保费示范目标、构成、率值与动作之间的关系。
第二节：口径的陷阱，运营看数据的常见困扰快速认识保单 / 保费、时间窗口和筛选范围带来的差异。
第三节：实战课 - 如何使用工作台使用现成报表和 BBC 漏斗数据集完成操作演示。
